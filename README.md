# ai-news-agent

`ai-news-agent` は、英語圏の AI 一次情報を収集し、日本語で整理して、AI 実務者が重要な変化を短時間で判断しやすくするためのリポジトリです。

現在は、manager 主導の最小マルチエージェント構成を前提に、仕様整理・設計・技術選定を進めています。
