### Manager の責務

- LangGraph 公式 docs / example / blog を web-search で確認した。
- supervisor / manager は実作業をしない薄い orchestrator として設計されることが多いと整理した。
- `ai-news-agent` でも manager は薄い orchestrator とする案Aを採用した。
- manager は `NewsRequest` 受け取り、初期探索計画、worker 委譲、shared state / judge 結果確認、追加探索判断、停止判定、翻訳対象確定、最終状態確定を担う。
- manager は fetch、本文抽出、normalization、dedupe、ranking score 算出、完全翻訳、Markdown 書き出しを持たない。

### Source Worker の最小構成

- source worker はソース種別ごとに細かく分ける案Aを採用した。
- MVP の worker は `official_blog_worker`、`github_release_worker`、`docs_update_worker`、`hacker_news_worker` とする。
- 採用理由は、成功 / 失敗ログを取りやすいこと、将来変更コストが小さいこと、並列化しやすいこと。
- `official_blog_worker` は複数の公式ブログ adapter を内部に持てる設計にする。
- MVP では `official_blog_worker` の child worker 化はせず、必要になった場合に adapter を child worker へ昇格できる余地を残す。
