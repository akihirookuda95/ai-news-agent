  - MVP の翻訳対象は `本文 / 見出し / 箇条書き` に固定。
  - `表 / コードブロック` は翻訳対象外。
  - GitHub Issue / PR や Reddit の議論翻訳は将来検討に回した。

- 性能条件:
  - `5記事で2分以内 / 10記事で3分以内` に確定。
  - 測定条件は `キャッシュなし / 音声なし / コマンド開始から Markdown 完了` に固定。

- TUI 対話:
  - MVP は `自由入力 + 件数 + 音声有無` の 3 問に最小化。
  - 対象ライブラリや媒体指定は必要なときだけ追加質問する方針にした。
